# API Reference

The full interactive reference (request/response schemas, try-it-out) is
auto-generated by FastAPI and served at **`/docs`** (Swagger UI) or
**`/redoc`** whenever the backend is running. This document is a map of what
exists and why — read it alongside `/docs`, not instead of it.

## Base URL & auth

All REST endpoints are under `/api/v1`. The WebSocket endpoint is not
versioned (`/ws/market`).

Every REST endpoint (except `/health` and `/`) requires an `X-API-Key`
header matching `Settings.api_key`. In `development` mode with the default
placeholder key (`change-me-in-production`), this check is skipped entirely
for zero-config local use — see `app/api/deps.py::require_api_key` and
`docs/ARCHITECTURE.md` §7 for why a shared-secret header is this project's
deliberate choice over full multi-user auth.

## Key endpoints

### `GET /api/v1/analysis?symbol=EURUSD&timeframe=H1&count=300`

Runs the full deterministic pipeline (`MarketAnalysisEngine`) and returns
indicators, structure (trend/BOS/CHOCH), liquidity (sweeps/order
blocks/FVGs), levels (S/R, supply/demand), session, and volatility. This is
the data every other "smart" endpoint is built from.

### `POST /api/v1/setups/generate`

```json
{ "symbol": "EURUSD", "timeframe": "H1", "include_ai_narrative": true }
```

Runs the analysis, scores confluence for both directions
(`strategies/confluence.py`), and — if either side clears the confidence
threshold — builds a concrete entry/SL/TP/RR proposal
(`strategies/setup_generator.py`). Always persists a `TradeSetup` row and
always returns the itemized `reasons` array, even when no valid setup was
found (in which case `status` is `INVALIDATED` and `ai_narrative` carries
the rejection reason). `include_ai_narrative: true` is best-effort — a
missing/failing AI provider never blocks the setup itself.

### `GET /api/v1/analysis/narrative?symbol=EURUSD`

Pure AI narration of the current analysis. Returns `502` if
`ANTHROPIC_API_KEY` isn't configured — unlike the setup-generation endpoint,
this endpoint's entire purpose *is* the AI call, so there's no "degrade
gracefully" path here.

### `POST /api/v1/screenshot/analyze` (multipart/form-data)

Fields: `file` (image/png, image/jpeg, or image/webp, ≤ `MAX_SCREENSHOT_SIZE_MB`),
optional `symbol_hint`, optional `journal_entry_id` to attach the analysis to
an existing trade. Runs the vision model with a strict JSON-schema prompt
(`services/ai/screenshot_analyzer.py`) and persists the structured result.

### `POST /api/v1/risk/lot-size`

```json
{
  "account_balance": 10000,
  "risk_percent": 1.0,
  "entry_price": 1.1000,
  "stop_loss": 1.0950,
  "symbol": "EURUSD"
}
```

Fixed-fractional position sizing, floored to the broker's lot step so
realized risk never exceeds the requested `risk_percent`.

### `GET /ws/market?symbol=EURUSD&timeframe=H1`

WebSocket. On connect, streams a JSON payload every
`MARKET_POLL_INTERVAL_SECONDS` (default 60s):

```json
{
  "type": "market_update",
  "symbol": "EURUSD",
  "timeframe": "H1",
  "price": 1.09349,
  "ema_trend_bias": "BUY",
  "rsi14": 55.9,
  "structure_trend": "BUY",
  "last_bos": { "direction": "BUY", "price": 1.09392 },
  "last_choch": null,
  "session": "NEW_YORK",
  "volatility_regime": "NORMAL"
}
```

Each connection runs its own independent poll loop (see
`app/websocket/market_stream.py`) rather than a shared broadcast — see the
docstring there for the trade-off. On a transient error the socket receives
`{"type": "error", "message": "..."}` instead of closing.

## Error shape

Every domain-level error (raised as a `FathirError` subclass) returns
`{"detail": "<message>"}` with an appropriate status code (`app/main.py`'s
`FathirError` handler). See `app/core/exceptions.py` for the full exception
hierarchy and their status codes (e.g. `InsufficientDataError` → 422,
`BrokerUnavailableError` → 503, `AIProviderError` → 502, `NotFoundError` →
404).

Request validation errors (malformed query params/body, caught by FastAPI
before a route body runs) instead return FastAPI/Pydantic's own shape —
`{"detail": [{"type": ..., "loc": [...], "msg": ...}, ...]}`, an array —
with status `422`.
